# 🌵 Minimal Blog Card - devChallenges #

Este proyecto es una tarjeta de blog minimalista diseñada para practicar el uso de Flexbox, Box Shadows y la estructura de componentes web responsivos. El diseño se centra en la limpieza visual y la jerarquía tipográfica.

### 🚀 Instalación y Uso Local ###

No se requieren dependencias externas ni servidores para ejecutar este proyecto. Sigue estos pasos:

1. **Clonar o Descargar:** Descarga los archivos del repositorio a tu computadora.

2. **Estructura de Carpetas:** Asegúrate de mantener la carpeta `img` en el mismo nivel que tu `index.html` para que la imagen del cactus se cargue correctamente.

- `/raiz-del-proyecto`

  - `index.html`
  - `styles.css`
  - `/img`
    - `Cactus.jpg`

3. **Ejecutar:** Haz doble clic en el archivo `index.html` para abrirlo en tu navegador predeterminado.

### 🛠️ Tecnologías Utilizadas ###

- **HTML5 Semántico:** Estructura clara utilizando etiquetas como `<main>`, `<section>` y `<footer>`.
- **CSS3 Custom Properties:** Estilos enfocados en la legibilidad y el diseño responsivo.
- **Google Fonts:** Uso de la fuente ***Sora*** para un look moderno y profesional.
- **Flexbox Layout:** Utilizado para el centrado de la tarjeta y el sistema de "Sticky Footer".

### 💡 Conceptos Clave Implementados ###
- **Sticky Footer:** Implementado con `min-height: 100vh` en el `body` para asegurar que el pie de página siempre esté al final de la pantalla.
- **Box Shadow:** Uso de sombras suaves y difusas para crear profundidad sin recargar el diseño.
- **UI Hierarchy:** Diferenciación visual entre la etiqueta ("Design"), el título y la descripción mediante el uso de pesos de fuente y colores.
